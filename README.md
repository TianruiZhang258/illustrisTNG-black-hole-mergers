# IllustrisTNG Black Hole Merger Analysis

## Overview
This project analyzes the formation and evolution of supermassive black holes using data from the IllustrisTNG cosmological simulation.

The focus is on:
- Black hole merger trees
- Mass evolution over cosmic time
- Accretion rates (mdot)
- Physical properties such as gas density (rho) and sound speed (cs)

## Methods
- Extracted and processed simulation data using Python
- Built merger trees to track black hole evolution
- Implemented time-series analysis for individual black holes
- Applied smoothing techniques (e.g., total variation denoising)

## Tools & Technologies
- Python (NumPy, Pandas, Matplotlib)
- h5py for simulation data handling
- Scientific computing and visualization

## Results
- Generated time evolution plots of black hole mass and accretion rates
- Identified dominant black holes in merger events
- Visualized merger histories and growth patterns
